## About Me

> I work on the part of software that has to keep running: backend services, data pipelines and, more recently, AI agents. I care about how systems hold up under real use: **clean APIs, scalable data architecture, observability and resilience**. I'm studying Computer Science in Computer Engineering at Cracow University of Technology while working commercially at SII Poland.

> I value consistency and hands-on practice over theory in isolation. The repositories here reflect that: **working systems, not tutorial reproductions.**

## What I Work On

- **Data engineering at SII:** delta-load ETL pipelines (Python, PostgreSQL, GitHub Actions, AWS Lambda), PySpark jobs, and migrating data sources into a Data Lakehouse using the medallion architecture. Observability through **Grafana** dashboards with custom HTML/CSS/JS panels.
- **AI agents:** building agents that help both developers and non-technical users in their daily work.
- **Backend services** in **Python (Django, FastAPI)** and **Java (Spring Boot)**: clean boundaries, testability, production-grade APIs.
- **Full-stack applications** pairing typed React/TypeScript frontends with FastAPI or Go backends.
- **Dockerized deployments**, CI/CD pipelines and SQL query optimization.
- **AI-assisted development** (Claude Code, GitHub Copilot) to move faster on scaffolding and debugging, not as a substitute for understanding the code.
