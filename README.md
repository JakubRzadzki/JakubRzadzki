## About

I build backend systems and care about how they hold up under real load. My focus is on **scalable architectures, clean APIs, and observability** — the parts of software that decide whether a system survives contact with production. I'm studying Computer Science in Computer Engineering at Cracow University of Technology while working commercially as a backend developer at SII Poland.

I value consistency and hands-on practice over theory in isolation. The repositories here reflect that: working systems, not tutorial reproductions.

## What I Work On

- Backend services in Python (Django, FastAPI) and Java, with an emphasis on clean boundaries and testability
- Full-stack applications pairing typed React frontends with well-designed APIs
- Dockerized deployments with CI/CD pipelines and Grafana-based monitoring
- ETL pipelines and SQL query optimization, including PySpark jobs and AWS-based workflows (S3, Lambda)

I also use AI-assisted development tooling (Claude Code, Cursor, Copilot) as part of my workflow — to move faster on scaffolding and debugging, not as a substitute for understanding the code.
